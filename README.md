# red-museos-caribe
Sistema de gestión y análisis de visitantes de la Red de Museos del Caribe, desarrollado en Python para la asignatura Fundamentos de Programación.
## Gestión del proyecto

El desarrollo del sistema se organiza mediante GitHub Projects, utilizando un tablero Kanban para gestionar las tareas pendientes, en proceso y finalizadas.

📋 [Ver tablero de desarrollo](https://github.com/orgs/museos-caribe-team/projects/3)
